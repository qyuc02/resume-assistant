# 简历助手 · 使用指南

一个跑在你自己电脑上的求职助手：把「经历 → 简历 → 投递 → 面试」一条龙管起来。经历只记一次，每份简历按岗位各写一套讲法。**数据只存在本机，不上传任何服务器。**

## 能做什么

| 页面 | 干什么 |
|---|---|
| **经历档案** | 把你做过的事（实习、项目、技能、证书…）记成一条条「事实」，记一次、长期复用 |
| **简历** | 从档案挑经历，按不同岗位各写一份，改说法、调顺序，导出 Word / 打印 PDF |
| **投递记录** | 加公司岗位、记 JD、推进面试阶段，投递时自动冻结当时的简历快照 |
| **学习中心** | 选定目标岗位，自动汇总成一份学习清单 |
| **设置** | 基本信息、AI Key、数据备份 / 导入 / 清空 |

面试准备与复盘放在**投递记录**里：进入某个岗位的详情，就能生成「可能被问的问题 + 答题要点」，并逐次记录面试复盘。

## 下载安装

到仓库的 **Releases** 页面下载最新版本：

- **Windows**：`简历助手 Setup x.x.x.exe`，双击安装。
- **macOS**：`简历助手-x.x.x-arm64.dmg`（Apple 芯片）或 `简历助手-x.x.x.dmg`（Intel 老款），拖进「应用程序」。

> macOS 未签名，首次打开若提示「无法验证开发者」，请在访达里**右键点它 → 打开**，之后正常双击即可。

## 三步上手

1. **经历档案**：先把你做过的事一条条记进去。
2. **简历**：新建简历，从档案挑经历，按岗位改说法，导出 Word / PDF。
3. **投递记录**：加岗位，随进度推进「待投递 → 已投递 → 笔试 → 一面 / 二面 / HR 面 → Offer」。

## AI 功能（可选）

不配置也能用全部功能。想用「诊断简历 / 生成面试题 / 解析导入的旧简历」，去 **设置 → AI** 填一个 DeepSeek 的 API Key。

只有你主动点 AI 按钮时，相关内容才会发给 DeepSeek，**不会自动上传**。

## 数据与备份

- 所有数据存在本机，软件不上传任何个人信息。
- 每次保存自动留一份备份（保留最近 20 份）。
- 换电脑或重装前，去 **设置 → 导出备份**，在新机器上 **导入备份** 即可。

## 常见问题

- **Mac 打不开**：右键点应用图标 → 打开（见上）。
- **数据存在哪**：Windows 在 `%APPDATA%\简历助手\data`，macOS 在 `~/Library/Application Support/简历助手/data`。
